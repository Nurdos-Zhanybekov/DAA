1. Problem
Sorting an array of integers in ascending order without built-in functions.

2. Approach
Used Bubble Sort via nested loops to repeatedly compare and swap adjacent elements until fully ordered.

3. Time Complexity
Time Complexity: O(n squared)
Explanation: Nested loops require comparing each element against all others in average and worst cases.

4. Reflection

More efficient approach: Yes, using merge sort or quicksort.

What to change: Apply divide and conquer recursion instead of nested loops.

Improved complexity: O(n log n).
